```bash
pnpm add @robomous/ui-core
```

Peer dependencies: `react` ≥ 19, `react-dom` ≥ 19, `tailwindcss` ≥ 4. Install them if the app does
not already carry them.

## The stylesheet

Import it once, in the app's CSS entry, before anything else that touches Tailwind:

```css
@import "tailwindcss";
@import "@robomous/ui-core/styles.css";

@source "./src";
```

The stylesheet is the contract: Tailwind v4 reads its `@theme` block, so `bg-primary` in a
component from this package and `bg-primary` written in the app are the same colour by
construction. It also closes Tailwind's default palette — `bg-red-500` and `text-emerald-700`
compile to nothing, in the app and in the package alike, because every colour here is a role.
The `@source "./src"` line is the app's own: `@robomous/ui-core` already scans its own components,
but Tailwind never looks inside `node_modules` on its own, and the app's roles only reach classes
written in the app's own sources.

## Import components by name

```tsx
import { Button, Card } from "@robomous/ui-core";
```

```tsx
<Card className="p-6">
  <Button>Save changes</Button>
</Card>
```

That is the whole surface: no config file, no theme provider to wrap the tree in.

## Dark mode

The stylesheet declares `@custom-variant dark (&:is(.dark *))`. Put `class="dark"` on `<html>` (or
any ancestor) and every role repoints itself — there is no second, dark-specific class to write at
the call site.

## Two families need a provider

Everything else composes freely. These two do not:

- **`Tooltip`** — `TooltipContent` needs a `TooltipProvider` somewhere above it in the tree.
  Mount one near the app root; it defaults `delayDuration` to `0`.
- **`Sidebar`** — `useSidebar` is called unconditionally, so even a lone `SidebarMenuButton`
  throws outside a `SidebarProvider`. Wrap the whole shell that contains a `Sidebar`.

```tsx
<TooltipProvider>
  <App />
</TooltipProvider>
```

`Toaster` is different again: mount it once, near the app root, and call `toast()` from anywhere
after that.

```tsx
import { Toaster } from "@robomous/ui-core";

<Toaster />;
```
