`@robomous/ui-core` is the Robomous design system: forty-five React components this repository owns
outright, over behaviour from Radix UI and Base UI — plus [cmdk](https://github.com/pacocoursey/cmdk)
under `Command` and [vaul](https://vaul.emilkowal.ski/) under `Drawer` — and the one stylesheet
they all resolve through. It is **built on top of [shadcn/ui](https://ui.shadcn.com)**: a
component starts as an item of the shadcn registry and is adapted here, but it is not an extension
of shadcn. From the moment it is installed, a component is ordinary source in this repository —
edited with a reason, a test and a review like any other file, never regenerated and never
compared back to upstream. shadcn supplies the starting point and the utility layer the stylesheet
vendors; Radix, Base UI, cmdk and vaul supply focus management, keyboard interaction and
dismissal; Robomous owns the API, the styling, the semantic variants and the public contract.

Every colour in the system is a role, not a pigment — `primary`, `muted`, `success`,
`destructive`, `overlay` and the rest — and both a light and a dark value are declared for each
one, so an interface never asserts that the page is white. Underneath the roles sits
Tailwind's palette, trimmed to eighteen scales: `neutral` is what the grey roles are made of, and
the hues are for data, not controls.

A consumer imports exactly two things:

```ts
import "@robomous/ui-core/styles.css"; // once, in the app's entry
import { Button, Card } from "@robomous/ui-core";
```

From here, [Installation](/docs/installation) covers pulling in the package, [Theming](/docs/theming)
covers the tokens and how to extend them, and [Components](/components) is every component, one
page each.
