## Usage

```tsx
import { Label, Switch } from "@robomous/ui-core";
```

```tsx
<div className="flex items-center gap-2">
  <Switch id="auto-save" defaultChecked />
  <Label htmlFor="auto-save">Auto-save annotations</Label>
</div>
```

Use a switch when the change is immediate, such as a settings row or a per-project preference. A
choice that waits for a Save button is a [Checkbox](/components/checkbox). A pressed/unpressed tool
in a toolbar is a [Toggle](/components/toggle) (`aria-pressed`).

## Composition

```text
Switch
```
