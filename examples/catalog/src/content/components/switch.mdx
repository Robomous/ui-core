## Usage

```tsx
import { Label, Switch } from "@robomous/ui-core";

export function TelemetryToggle() {
  return (
    <div className="flex items-center gap-2">
      <Switch id="telemetry" defaultChecked />
      <Label htmlFor="telemetry">Live telemetry</Label>
    </div>
  );
}
```

<Callout title="Switch or Checkbox?">
  Use a switch when the change is immediate: a settings row or a per-project preference. A choice
  that waits for a Save button is a [Checkbox](/components/checkbox). A pressed or unpressed tool in
  a toolbar is a [Toggle](/components/toggle), which carries `aria-pressed`.
</Callout>

## Composition

```text
Switch
```

A switch has no text of its own. Put the label before it in a horizontal `Field`, or beside it with a
`Label` and `htmlFor`.

## Examples

### Controlled

Use `checked` and `onCheckedChange` when something else on screen follows the switch, such as a
status badge or a request. Here the badge states the result of the flip, so the reader never has to
guess what "on" means.

<Preview demo="switch/controlled">
  <Controlled client:load />
</Preview>

### In a form

Give the switch a `name` and Radix adds a hidden native input inside a `<form>`. It posts `on`
when the switch is on and sends nothing when it is off, as a native checkbox does. Pass `value` to
post something else.

<Preview demo="switch/in-form">
  <InForm client:load />
</Preview>

### Sizes

`size` takes `default` or `sm`, carried as `data-size` so the thumb scales with the track. Use `sm`
where the row is dense, such as a table cell or a sidebar list; the demo lists the same sensors at both sizes.

<Preview demo="switch/sizes">
  <Sizes client:load />
</Preview>

### Invalid

`aria-invalid` paints the destructive ring, as on every other control; `data-invalid` on the `Field`
colours its label. Use it when the switch cannot be turned on yet, and say what is missing.

<Preview demo="switch/invalid">
  <Invalid client:load />
</Preview>

### Disabled

Disabled drops to half opacity and keeps the arrow cursor. Lead with the reason in the label, since
a locked switch gives the reader nothing to act on.

## Guidelines

<Guidelines
  do={[
    'Name the setting, not the action: "Live telemetry", not "Turn on live telemetry".',
    "Apply the change as soon as the switch moves, and confirm it where the reader is looking.",
    "Add a description when the on state has side effects the label does not show.",
    'Use `size="sm"` in dense rows, and keep one size within a list.',
  ]}
  dont={[
    "Don't use a switch for a choice that needs a Save button; that is a `Checkbox`.",
    "Don't use a switch for a tool in a toolbar; that is a `Toggle`.",
    "Don't relabel the switch when it flips; the label stays and the position carries the state.",
    "Don't use two switches to pick between exclusive options; use a `RadioGroup`.",
  ]}
/>

## Accessibility

A `button` with `role="switch"` and `aria-checked`, so a screen reader announces "on" or "off" rather
than "pressed". The hit area extends past the small track, and a `Label` with `htmlFor` makes the text
a target too.
