## Usage

```tsx
import { Kbd, KbdGroup } from "@robomous/ui-core";
```

```tsx
<KbdGroup>
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

A lone key is just a `Kbd`; reach for `KbdGroup` only once there is more than one to read together.

## Composition

```text
Kbd
KbdGroup
└─ Kbd
```

## Chord

`KbdGroup` holds a chord: the keys read together as one shortcut, not a list of separate ones.

## Inside a button

`data-icon="inline-end"` pads a `KbdGroup` the same way it pads an icon, so a shortcut sits at the
label's edge.
