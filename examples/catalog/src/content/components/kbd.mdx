## Usage

```tsx
import { Kbd, KbdGroup } from "@robomous/ui-core";

export function ApproveHint() {
  return (
    <p>
      Approve the frame with{" "}
      <KbdGroup>
        <Kbd>⌘</Kbd>
        <Kbd>Enter</Kbd>
      </KbdGroup>
    </p>
  );
}
```

<Callout title="It documents a shortcut; it does not create one">
  `Kbd` only draws the key. Binding the shortcut is your job, and the two must stay in step: a hint
  that shows `⌘K` over a handler that listens for something else is worse than no hint.
</Callout>

## Composition

```text
Kbd
KbdGroup
└─ Kbd
```

## Examples

### Chord

`KbdGroup` holds a chord: keys that are pressed together and read as one shortcut, not a list of
separate ones. Use it for a shortcut sheet, where each action is paired with its keys.

<Preview demo="kbd/chord">
  <Chord client:load />
</Preview>

### Single key

A lone `Kbd` sits inline with body text, sized to the line rather than as a boxed control. Reach
for `KbdGroup` only once there is more than one key to read together.

<Preview demo="kbd/single">
  <Single client:load />
</Preview>

### Inside a button

`data-icon="inline-end"` pads a `KbdGroup` the same way it pads an icon, so the shortcut sits at the
label's edge. The button stays the control; the keys are a reminder of the faster path.

<Preview demo="kbd/in-button">
  <InButton client:load />
</Preview>

### Inside a tooltip

`Kbd`'s background and text recolour automatically inside a `TooltipContent`, so it reads on the
tooltip's own fill instead of the page's. This is the place for the shortcut of an icon-only button.

### By platform

Keycaps are plain children, so the modifier can follow the reader's platform. Render the neutral
form first and switch after mount, so server and client markup agree and nothing flashes in the
wrong key.

## Accessibility

`Kbd` renders a native `<kbd>`, which marks the text as keyboard input but adds no role and is not
focusable. It is `pointer-events-none` and `select-none`, so it never intercepts a click on the
control it decorates. Screen readers announce symbols such as `⌘` inconsistently; where the key
matters, include its name as visually hidden text.
