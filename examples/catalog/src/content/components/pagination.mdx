## Usage

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from "@robomous/ui-core";
```

```tsx
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="?page=1" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="?page=2" isActive>
        2
      </PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="?page=3" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

`PaginationLink` renders a `Button` under the hood, but `asChild` hands its classes to the `<a>` you
give it, so the page still navigates like a link.

## Composition

```text
Pagination
└─ PaginationContent
   ├─ PaginationItem
   │  ├─ PaginationLink
   │  ├─ PaginationPrevious
   │  └─ PaginationNext
   └─ PaginationEllipsis
```

## Default

Every step, including the numbers, is a real anchor: middle-click and open-in-new-tab both work,
which a `<button onClick>` page control can't offer.

## At the start

An anchor has no `disabled` attribute, so the first page mutes Previous by hand: `aria-disabled`
plus a dimmed, inert class.
