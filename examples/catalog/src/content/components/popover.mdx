## Usage

```tsx
import {
  Button,
  Input,
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from "@robomous/ui-core";

export function RenameRobot() {
  return (
    <Popover>
      <PopoverTrigger asChild>
        <Button variant="outline">Rename robot</Button>
      </PopoverTrigger>
      <PopoverContent>
        <PopoverHeader>
          <PopoverTitle>Rename</PopoverTitle>
          <PopoverDescription>Shown in the fleet list and on mission logs.</PopoverDescription>
        </PopoverHeader>
        <Input defaultValue="Atlas" aria-label="Robot name" />
        <Button size="sm">Save</Button>
      </PopoverContent>
    </Popover>
  );
}
```

<Callout title="There is no PopoverClose">
  Nothing inside the content closes it on its own. To close from a Save or Cancel button, keep
  `open` in state and set it to `false`. A click outside or Escape still dismisses it.
</Callout>

## Composition

```text
Popover
├─ PopoverTrigger
├─ PopoverAnchor              optional; positions the content against another element
└─ PopoverContent             w-72 by default; portals itself
   ├─ PopoverHeader           optional layout
   │  ├─ PopoverTitle
   │  └─ PopoverDescription
   └─ …your content
```

## Examples

### Rename

The classic: a single field, opened from the thing it changes. `PopoverContent` is free-form beyond
the optional header, so a form drops straight in. With no `PopoverClose`, the demo owns `open` and
closes it on save.

### Choosing several options

A popover stays open while the reader interacts with it, so it suits a multi-select that a menu
would close after every pick. Show the result on the trigger, here as a count, so the choice is
visible once the popover is gone.

### Aligned to an edge

`align` sets which edge of the trigger the content lines up with: `start`, `center` (the default)
or `end`. A trigger on the trailing edge of a card opens with `align="end"`, so the popover grows
inward. `side` and `sideOffset` work the same way.

<Preview demo="popover/align">

</Preview>

### Anchored elsewhere

`PopoverAnchor` positions the content against a different element than the one that opens it. Here
the popover hangs from the camera's name rather than the info button beside it.

## Accessibility

The trigger carries `aria-haspopup="dialog"` and `aria-expanded`, and the content is a
`role="dialog"` surface that Radix focuses on open and returns focus from on close. Unlike a
Dialog, the page behind stays interactive.
