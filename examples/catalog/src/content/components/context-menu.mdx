## Usage

```tsx
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuTrigger,
} from "@robomous/ui-core";

export function FrameTile() {
  return (
    <ContextMenu>
      <ContextMenuTrigger className="rounded-lg border p-6">frame-000184.jpg</ContextMenuTrigger>
      <ContextMenuContent>
        <ContextMenuItem>Copy link</ContextMenuItem>
        <ContextMenuItem variant="destructive">Delete</ContextMenuItem>
      </ContextMenuContent>
    </ContextMenu>
  );
}
```

<Callout title="Mirror every action elsewhere" tone="warning">
  Nothing signals that a right-click menu exists, and not every reader can open one. Anything it
  offers should also be reachable from a visible control, such as a row's action menu.
</Callout>

## Composition

```text
ContextMenu
├─ ContextMenuTrigger           the area itself, not a button; select-none
└─ ContextMenuContent           portals itself; opens at the pointer
   ├─ ContextMenuLabel
   ├─ ContextMenuGroup
   │  └─ ContextMenuItem
   │     └─ ContextMenuShortcut
   ├─ ContextMenuCheckboxItem
   ├─ ContextMenuRadioGroup
   │  └─ ContextMenuRadioItem
   ├─ ContextMenuSeparator
   └─ ContextMenuSub
      ├─ ContextMenuSubTrigger
      └─ ContextMenuSubContent
         └─ ContextMenuItem
```

## Examples

### A tile

The trigger is whatever area should answer a right-click, so it wraps real content rather than a
button. A label names the object, a group holds the common actions with their shortcuts, and the
destructive one comes last behind a separator.

### At the pointer

When the action depends on where the reader clicked, record the position in the trigger's own
`onContextMenu` and read it back from the item. Radix still opens the menu; your handler only
runs first.

</Preview>

### View options

Checkbox items suit toggles for how something is shown. Checked, unchecked and indeterminate sit on
the same axis as `DropdownMenuCheckboxItem`: the dash says an overlay is on for some zones, not
all of them.

### Submenu

A submenu can hold its own radio group, so a destination is chosen without leaving the card the
menu opened from. It opens on hover or the right arrow, and shares the parent's rule of no exit
animation.

## Guidelines

<Guidelines
  do={[
    "Use it as a shortcut to actions on the object under the pointer.",
    "Offer the same actions from a visible control, like a row's action menu.",
    "Keep the menu short and put the destructive item last, behind a separator.",
    "Label the object with a `ContextMenuLabel` when the menu covers more than one thing.",
  ]}
  dont={[
    "Don't make it the only way to reach an action.",
    "Don't use it for a menu opened from a button; that is a DropdownMenu.",
    "Don't put it on text the reader may want to select or copy, since it replaces the browser's menu.",
    "Don't put forms or long content inside it.",
  ]}
/>

## Accessibility

Radix gives the surface `role="menu"` and its items `menuitem`, `menuitemcheckbox` or
`menuitemradio`, and moves focus into the menu when it opens. Touch devices open it with a
long-press, and the browser's own menu is suppressed only over the trigger.
