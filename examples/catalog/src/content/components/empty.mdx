## Usage

```tsx
import {
  Button,
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from "@robomous/ui-core";
import { TimerIcon } from "@robomous/ui-core/icons";

export function NoRuns() {
  return (
    <Empty className="border">
      <EmptyHeader>
        <EmptyMedia variant="icon">
          <TimerIcon />
        </EmptyMedia>
        <EmptyTitle>No training runs yet</EmptyTitle>
        <EmptyDescription>Start a run to fine-tune detector-v3.2.</EmptyDescription>
      </EmptyHeader>
      <EmptyContent>
        <Button>Start a run</Button>
      </EmptyContent>
    </Empty>
  );
}
```

<Callout title="The dashed border is opt-in">
  `Empty` sets `border-dashed` but no border width, so by itself it draws no edge. Add `border` to
  make it read as an empty container, and leave it off when the panel already sits inside a card
  or a bordered list.
</Callout>

## Composition

```text
Empty
├─ EmptyHeader
│  ├─ EmptyMedia            variant="default" | "icon"
│  ├─ EmptyTitle
│  └─ EmptyDescription
└─ EmptyContent             optional, the action or actions
```

## Examples

### Icon media

`EmptyMedia` with `variant="icon"` sets the icon in a muted square, the usual mark for a first-run
state. `EmptyContent` holds the action that resolves the panel, so the way forward is the last thing
the reader sees.

<Preview demo="empty/icon">

</Preview>

### Default media

`variant="default"` leaves the icon unstyled, for a larger mark that carries the panel on its own
rather than sitting in a chip. Size and colour come from the icon's own `className`.

<Preview demo="empty/default-media">
  <DefaultMedia client:load />
</Preview>

### More than one way in

When there are two real routes forward, put both in `EmptyContent`. Make the first the primary
action and the second an `outline` button, so the choice has an obvious default.

<Preview demo="empty/actions">
  <Actions client:load />
</Preview>

### No results

A filtered list that matches nothing is not an error. Say why it is empty and offer to undo the
cause, here a `Clear filters` button. A panel with nothing to do can leave `EmptyContent` out.

</Preview>

### Compact

`Empty` is generous by default, with `py-16`. Inside a popover, a sidebar or a small card, override
the padding with `className` and shrink the title to match the surface around it.

## Guidelines

<Guidelines
  do={[
    "Name what is missing in the title: \"No training runs yet\".",
    "Use the description to say why it matters or how to fill it, in one sentence.",
    "Offer one primary action that creates the first item.",
    "Explain a filtered-empty list differently from a never-filled one.",
  ]}
  dont={[
    "Don't leave a list blank with no explanation.",
    "Don't use an empty state to report a failure; use `ErrorMessage` or an `Alert`.",
    "Don't put several competing buttons of the same weight in `EmptyContent`.",
    "Don't write \"Nothing here\"; tell the reader what would be here.",
  ]}
/>

## Accessibility

`Empty` is a set of plain `div`s, with no role of its own: the title and description are read as
ordinary text in the document flow. That makes the copy do the work, so it should make sense without
the icon. The icon inside `EmptyMedia` is decorative, and any action in `EmptyContent` is a normal
button or link in the tab order.
