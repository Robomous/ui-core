## Usage

```tsx
import { Separator } from "@robomous/ui-core";
```

```tsx
<div>batch-0041</div>
<Separator />
<div>batch-0042</div>
```

`decorative` defaults to `true`, because most separators repeat a grouping the layout already
shows; set it to `false` only when the rule is the only thing marking a real boundary for assistive
tech.

## Composition

```text
Separator
```
