## Usage

```tsx
import { Field, FieldLabel, Textarea } from "@robomous/ui-core";

export function BatchNotes() {
  return (
    <Field>
      <FieldLabel htmlFor="batch-notes">Batch notes</FieldLabel>
      <Textarea id="batch-notes" placeholder="Anything annotators should know?" />
    </Field>
  );
}
```

<Callout title="No rows, no resize handle" tone="note">
  The height comes from the content, down to a `min-h-16` floor, so a `rows` prop is rarely needed.
  `field-sizing-content` is a recent CSS feature; in a browser without it the box falls back to a
  fixed height and scrolls.
</Callout>

## Composition

```text
Textarea
```

## Examples

### Empty

Empty, it is a two-line box with a placeholder that says what belongs inside. Always pair it with a
visible label; the placeholder is a hint for the first keystroke, not the field's name. The action
beside it stays off until there is text.

</Preview>

### Grows with content

The box grows as lines are added instead of scrolling inside a fixed height, and there is no resize
handle to drag. The reader always sees everything they wrote, and the page decides how much
room it can give.

<Preview demo="textarea/grows-with-content">

</Preview>

### Taller minimum

The `min-h-16` floor is a default, not a rule. Raise it with `className` when the answer is
expected to be a paragraph, so the field looks like it invites one. The two boxes below are the
same component at both floors.

<Preview demo="textarea/min-height">

</Preview>

### Character count

For a limit, set `maxLength` on the control and show the count beside the description. Use
`tabular-nums` so the number doesn't jitter while it changes. The browser stops input at the limit,
so there is no error state to design. The count turns to the warning colour for the last twenty
characters.

<Preview demo="textarea/character-count">

</Preview>

### Invalid

`aria-invalid` switches on the destructive border and ring, the same attribute a screen reader
reads. Here the rule is a minimum length: the error appears while the text is too short and clears
the moment it isn't, which also enables the action that was blocked.

<Preview demo="textarea/invalid">
  <Invalid client:load />
</Preview>

### Disabled

Disabled keeps the arrow cursor and drops to half opacity: nothing will respond to focus or a
keystroke. For text the reader should still select and copy, use `readOnly` instead.

## Guidelines

## Accessibility

A native `<textarea>`, so it is exposed as a multi-line text box, with its value, selection and
form behaviour from the platform. Name it with a `Label` and point `aria-describedby` at its
description or error.
