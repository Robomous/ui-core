## Usage

```tsx
import { Textarea } from "@robomous/ui-core";
```

```tsx
<Textarea placeholder="What is this dataset for?" aria-label="Notes" />
```

`field-sizing-content` sets the height from the content, down to a `min-h-16` floor, so a `rows`
prop is rarely needed.

## Composition

```text
Textarea
```

## Grows with content

The box grows as lines are added instead of scrolling inside a fixed height — there is no resize
handle to drag.

## Disabled

Disabled keeps the arrow cursor: nothing will respond to focus or a keystroke.
