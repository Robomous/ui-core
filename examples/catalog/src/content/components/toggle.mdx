## Usage

```tsx
import { Toggle } from "@robomous/ui-core";
```

```tsx
<Toggle aria-label="Bold">
  <BoldIcon />
</Toggle>
<Toggle variant="outline" defaultPressed aria-label="Italic">
  <ItalicIcon />
</Toggle>
```

A bare-icon `Toggle` carries no visible label, so give it an `aria-label` describing what it turns
on.

## Composition

```text
Toggle
└─ <StarIcon data-icon="inline-start" />
```

## Variants

Two variants: `default` sits flush until pressed, `outline` keeps a border so a toolbar with no
surrounding track still reads as a set of controls.

An icon and a word together read as one control; `data-icon="inline-start"` pads the icon the
