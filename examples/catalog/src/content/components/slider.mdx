## Usage

```tsx
import { Slider } from "@robomous/ui-core";
```

```tsx
<Slider aria-label="Confidence threshold" defaultValue={[60]} step={5} />
```

The value is always an array. `aria-label` and `aria-labelledby` are forwarded to every thumb
rather than the root, because the thumb is the element with `role="slider"`. A `<label htmlFor>`
names nothing here, so point `aria-labelledby` at the visible label instead. With no value, the
slider starts at `[min]` with one thumb.

## Composition

```text
Slider
```

## Range

Two values render two thumbs; the filled track between them is the selection.
