## Usage

```tsx
import { Badge } from "@robomous/ui-core";

export function RunRow() {
  return (
    <div className="flex items-center gap-2">
      <span className="font-mono">run-0187</span>
      <Badge variant="success">finished</Badge>
    </div>
  );
}
```

<Callout title="A badge describes, it does not act">
  A `Badge` is a `span`. Make it a link with `asChild` and an `<a>`, never an `onClick`; for
  something that toggles or runs, use a `Toggle` or a `Button`.
</Callout>

## Composition

```text
Badge
└─ <Icon data-icon="inline-start" | "inline-end" />   optional
```

## Examples

### Variants

Ten variants in two groups. The plain hierarchy is `default`, `secondary`, `outline`, `quiet`,
`ghost` and `link`; `quiet` is the muted one, for a state that should not ask for attention. The
status roles are `success`, `info`, `warning` and `destructive`; they share one recipe, a soft
surface in the role under ink in the same role, because colour is never the only signal and status
is never a stroke.

### With an icon

An icon gives the status a shape as well as a colour, which helps when colour alone is not enough.
`data-icon="inline-start"` or `"inline-end"` trims the padding on that side so the optical spacing
stays even.

### Counts

Put a badge inside a button's label to show how many items are behind it. Choose the variant by what
the number means: `destructive` for failures, `default` for work waiting, `quiet` for a total that
needs no action.

### As a link

`asChild` hands the badge's classes to the child, so a label can lead to a filtered view and still be
a real anchor: it is focusable, shows its URL and gets a hover state.

### In context

A status badge reads fastest beside the row it describes, not inside a sentence. Left-align it in
its own column so the eye can scan down the states.

## Guidelines

<Guidelines
  do={[
    "Use one or two words in lowercase that name the state: `finished`, `diverged`.",

    "Pair colour with text, and with an icon when the state is easy to miss.",

  dont={[

## Accessibility

A `Badge` is a plain `span` with no role, so its text is read in the flow of the line around it.
That makes the words carry the meaning: never leave a status to colour alone. With `asChild` on an
anchor it is a normal link, focusable with a visible ring.
