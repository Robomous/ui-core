## Usage

```tsx
import { Button, Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@robomous/ui-core";
```

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger asChild>
      <Button variant="ghost">Hover me</Button>
    </TooltipTrigger>
    <TooltipContent>Saves the current view</TooltipContent>
  </Tooltip>
</TooltipProvider>
```

Mount one `TooltipProvider` near the root of the app; every `Tooltip` beneath it shares its
`delayDuration`, which defaults to `0` rather than the usual pause before showing.

## Composition

```text
TooltipProvider
└─ Tooltip
   ├─ TooltipTrigger
   └─ TooltipContent
```

## Default

`TooltipContent` paints `bg-foreground text-background`, so it inverts with the page instead of
carrying a fixed colour of its own.

## With a shortcut

A `Kbd` placed inside `TooltipContent` restyles itself onto the painted background — no prop to
set, the selector reads `data-slot="tooltip-content"` on its parent.
