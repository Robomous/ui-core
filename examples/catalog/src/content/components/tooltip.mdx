## Usage

```tsx
import { Button, Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@robomous/ui-core";
import { ZoomInIcon } from "@robomous/ui-core/icons";

export function ZoomControl() {
  return (
    <TooltipProvider>
      <Tooltip>
        <TooltipTrigger asChild>
          <Button variant="ghost" size="icon" aria-label="Zoom in">
            <ZoomInIcon />
          </Button>
        </TooltipTrigger>
        <TooltipContent>Zoom in</TooltipContent>
      </Tooltip>
    </TooltipProvider>
  );
}
```

<Callout title="A tooltip describes; it does not name">
  The tooltip is announced as the trigger's description. An icon-only button still needs its own
  `aria-label`, and anything the reader must know to proceed belongs in the page, not in a tooltip.
</Callout>

## Composition

```text
TooltipProvider                shared delayDuration, 0 by default; mount once near the root
└─ Tooltip
   ├─ TooltipTrigger
   └─ TooltipContent           inverted surface with an arrow; a Kbd inside restyles itself
```

## Examples

### Naming icon buttons

The most common use. Wrap the group in one `TooltipProvider`, give each button its `aria-label`
and repeat it as the tooltip text. Because `delayDuration` is `0`, moving along the row shows
each name at once.

### Placement

`side` picks the edge the tooltip opens from, and the arrow and slide-in direction follow it. A
vertical tool palette opens to the `right`, away from the canvas it controls.

</Preview>

### Keyboard shortcuts

Put a `Kbd` after the label to teach the shortcut where the reader is already looking. It
restyles itself onto the tooltip's surface, so there is nothing to configure.

<Preview demo="tooltip/with-kbd">
  <WithKbd client:load />
</Preview>

### Explaining a disabled button

A disabled button fires no pointer or focus events, so a tooltip on it never opens. Wrap it in a
focusable element and put the trigger on the wrapper, so the reader learns why the action is
unavailable.

<Preview demo="tooltip/disabled">
  <Disabled client:load />
</Preview>

### Truncated text

A tooltip can reveal the full value behind an ellipsis. Raise `delayDuration` on the provider for
this, so a pointer crossing text does not make tooltips flash, and give the trigger `tabIndex={0}`
so keyboard users can reach it.

## Guidelines

<Guidelines
  do={[
    "Keep it to a few words; a tooltip is a label, not a paragraph.",
    "Pair an icon-only button's `aria-label` with the same text in the tooltip.",
    "Add a `Kbd` when the action has a shortcut worth learning.",
    "Wrap a disabled control in a focusable element so the reason can be shown.",
  ]}
  dont={[
    "Don't put links, buttons or any interactive content inside; use a Popover.",
    "Don't hide required information in one; touch users never see it.",
    "Don't repeat a visible label; a button that already says \"Save\" needs no tooltip.",
    "Don't nest multiple `TooltipProvider` components unless you need a different delay.",
  ]}
/>

## Accessibility

Radix links the content to the trigger through `aria-describedby` and renders it with
`role="tooltip"`. It opens on hover and on keyboard focus, and it stays open while the pointer
moves onto its content.
