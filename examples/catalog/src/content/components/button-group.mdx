## Usage

```tsx
import { Button, ButtonGroup, ButtonGroupSeparator } from "@robomous/ui-core";
```

```tsx
<ButtonGroup>
  <Button variant="outline">Publish</Button>
  <ButtonGroupSeparator />
  <Button variant="outline" size="icon" aria-label="More publish options">
    <ChevronDownIcon />
  </Button>
</ButtonGroup>
```

Only a child carrying a `data-slot` gets rounded, so a plain `<div>` dropped in the middle leaves
the corners to its neighbours instead of breaking the shape.

## Composition

```text
ButtonGroup
├─ ButtonGroupText
├─ ButtonGroupSeparator
└─ Button / Input / ...
```

## Text and input

Every segment carries a `data-slot`, which is what the group reads to round only the first and the
last child.

## Split

`ButtonGroupSeparator` is a `Separator` underneath: it inherits its orientation from the group
instead of setting one of its own.

</Preview>

## Vertical

`orientation="vertical"` stacks the segments and rounds the top and bottom instead of the ends.
