## Usage

```tsx
import { Alert, AlertTitle, AlertDescription } from "@robomous/ui-core";
```

```tsx
<Alert>
  <AlertTitle>Ingest paused</AlertTitle>
  <AlertDescription>The bucket is unreachable. Retrying in a minute.</AlertDescription>
</Alert>
```

`default`, `warning` and `destructive` render `role="alert"`, which announces the mount itself;
`info` and `success` render `role="status"`, announced politely. There is no live-region prop to set
and nothing else to wire up.

## Composition

```text
Alert
├─ <TriangleAlertIcon />
├─ AlertTitle
├─ AlertDescription
└─ AlertAction
```

## Variants

`default` is a plain notice on the card surface. `info`, `success`, `warning` and `destructive` are
tonal: the status's surface role under its ink role, with the icon and description in that same ink.
No variant recolours the border around it — status is never a stroke.

## Action

`AlertAction` sits absolute at the top right; the alert detects it (`has-data-[slot=alert-action]`)
and pads its content clear on its own, so the title and description never run under it.
