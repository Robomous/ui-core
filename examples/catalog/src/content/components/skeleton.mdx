## Usage

```tsx
import { Skeleton } from "@robomous/ui-core";
```

```tsx
<Skeleton className="h-32 w-full rounded-lg" />
<Skeleton className="h-4 w-3/4" />
```

`Skeleton` carries no shape of its own: every size and radius comes from the `className` you pass,
matched to the content it stands in for.

## Composition

```text
Skeleton
```
