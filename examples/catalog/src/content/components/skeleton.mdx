## Usage

```tsx
import { Skeleton } from "@robomous/ui-core";

export function ModelSkeleton() {
  return (
    <div className="flex flex-col gap-2">
      <Skeleton className="h-32 w-full rounded-lg" />
      <Skeleton className="h-4 w-3/4" />
    </div>
  );
}
```

<Callout title="A skeleton has no shape of its own">
  Every size and radius comes from `className`, so an unstyled `Skeleton` is an empty box. Copy the
  dimensions of the content it replaces: a line is `h-4` and a width, an avatar is `size-10 rounded-full`.
</Callout>

## Composition

```text
Skeleton     one pulsing block, composed into the shape of the content
```

## Examples

### Card

A preview above two caption lines. Use `aspect-video` or another ratio on media instead of a fixed
height, so the placeholder scales with its container exactly as the image will.

### List rows

An avatar beside two lines, repeated for a members list still loading. Show roughly as many rows as
you expect, so the page does not grow or collapse when real data arrives.

### Paragraph

Text is a stack of lines, with the last one shorter. Give lines different widths and they read as
prose, where a column of equal bars reads as a loading error.

### Table

Keep real headings, since they are known, and put skeletons only in the cells that wait for data.
The columns hold their widths, and the table does not jump when rows load.

## Guidelines

<Guidelines
  do={[
    "Match the real layout: same height, width, radius and spacing as the content.",
    "Mark the loading region with `aria-busy` so assistive technology knows it will change.",
    "Show skeletons for content with a known shape, such as cards, rows and tables.",
    "Vary line widths so text placeholders look like text.",
  ]}
  dont={[
    "Don't use skeletons for a wait you can't shape; use a `Spinner`.",
    "Don't animate a skeleton for content that failed to load; show an error or an empty state.",
    "Don't show more placeholder rows than the page will realistically hold.",
    "Don't leave a skeleton up with no timeout.",
  ]}
/>

## Accessibility

A `Skeleton` is a plain, silent `div`: it has no role and announces nothing, which is right for a
decoration. Mark the region that is loading with `aria-busy="true"` and clear it when the content
lands. The pulse is a CSS animation that collapses under `prefers-reduced-motion`.
