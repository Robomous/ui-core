## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@robomous/ui-core";
```

```tsx
<ToggleGroup type="single" defaultValue="left" aria-label="Alignment">
  <ToggleGroupItem value="left" aria-label="Left">
    <AlignLeftIcon />
  </ToggleGroupItem>
  <ToggleGroupItem value="center" aria-label="Centre">
    <AlignCenterIcon />
  </ToggleGroupItem>
</ToggleGroup>
```

Items inherit the group's `variant` and `size` — set them once on `ToggleGroup`, not on each
`ToggleGroupItem`.

## Composition

```text
ToggleGroup
└─ ToggleGroupItem
```

## Multiple selection

`type="multiple"` behaves like independent pressed buttons: any number of segments can stay on
at once.

## Welded segments

`spacing={0}` welds the segments into one control, sharing borders instead of gaps — the first
and last items pick up the group's own corner radius.

## Vertical

`orientation="vertical"` stacks the segments and stretches them to one width instead of a row.
