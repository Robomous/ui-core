## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@robomous/ui-core";
import { LayoutGridIcon, ListIcon } from "@robomous/ui-core/icons";

export function LayoutSwitch() {
  return (
    <ToggleGroup type="single" defaultValue="grid" aria-label="Dataset layout">
      <ToggleGroupItem value="grid" aria-label="Grid">
        <LayoutGridIcon />
      </ToggleGroupItem>
      <ToggleGroupItem value="list" aria-label="List">
        <ListIcon />
      </ToggleGroupItem>
    </ToggleGroup>
  );
}
```

<Callout title="A single group can end up empty" tone="warning">
  In `type="single"`, pressing the active item turns it off and `onValueChange` receives an empty
  string. If one option must always be chosen, control the value and ignore the empty one:
  `onValueChange={(next) => next && setValue(next)}`.
</Callout>

## Composition

```text
ToggleGroup
└─ ToggleGroupItem
   └─ <Icon data-icon="inline-start" | "inline-end" />   optional
```

## Examples

### Single selection

`type="single"` allows at most one pressed item and takes a string `value`. Reach for it when the
options are views of the same thing, such as a grid, a list or a table, and for a toolbar where
the whole group is one icon-only control.

<Preview demo="toggle-group/single">
  <Single client:load />
</Preview>

### Multiple selection

`type="multiple"` takes an array in `value`, so any number of items can stay on. It suits layers
you can show together, such as boxes, masks and labels over a frame. Text next to each icon makes
the set readable without hovering.

<Preview demo="toggle-group/multiple">
  <Multiple client:load />
</Preview>

### Welded segments

`spacing={0}` removes the gap and welds the segments into one control, sharing borders. The first
and last item take the group's corner radius. This is the shape for a short range picker, and the
selection drives something else, so it is controlled here.

<Preview demo="toggle-group/welded">
  <Welded client:load />
</Preview>

### Sizes

`size` and `variant` are set once on the group and every item inherits them, so you cannot end up
with mismatched segments. The sizes match `Toggle`: `sm`, `default` and `lg`.

<Preview demo="toggle-group/sizes">
  <Sizes client:load />
</Preview>

### Vertical

`orientation="vertical"` stacks the items, stretches them to one width and turns the arrow keys
to the column's axis: up and down move between items. Use it for a tool rail along the edge of a
canvas or a map. Give the group a width to set the rail's thickness.

## Accessibility

In `type="single"` the group is a `radiogroup` and each item a `radio` with `aria-checked`. In
`type="multiple"` the group is a `toolbar` and each item a button with `aria-pressed`. Either way the
group is one tab stop with roving focus, so the arrow keys along its `orientation` move between
items.
