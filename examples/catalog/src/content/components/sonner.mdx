## Usage

```tsx
import { Toaster, toast } from "@robomous/ui-core";
```

```tsx
// once, near the app root
<Toaster />;

// anywhere below it
toast("Saved");
```

This catalog already mounts a single `Toaster` in its layout; an app does the same, once. Every
call to `toast` from anywhere in the tree reaches that one mount point.

## Composition

```text
Toaster
toast()
```

## Intents

Four intents beyond a plain `toast()`: `success`, `warning`, `info`, `error`. Each supplies its own
icon, and there is no `variant` prop to reach for instead — the function called is the state.

`description` adds a second line under the title, for detail that does not belong in the title

## Promise

`toast.promise` swaps a loading toast for a success or error one, decided by the promise it wraps,
so the reader is never left checking whether anything happened.
