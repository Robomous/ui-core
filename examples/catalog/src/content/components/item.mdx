## Usage

```tsx
import { Item, ItemContent, ItemDescription, ItemMedia, ItemTitle } from "@robomous/ui-core";
import { BotIcon } from "@robomous/ui-core/icons";

export function RobotRow() {
  return (
    <Item variant="outline">
      <ItemMedia variant="icon">
        <BotIcon />
      </ItemMedia>
      <ItemContent>
        <ItemTitle>rb-07 Atlas</ItemTitle>
        <ItemDescription>Docked at bay 3, battery 82%</ItemDescription>
      </ItemContent>
    </Item>
  );
}
```

<Callout title="Actions live beside the content">
  Put trailing controls in `ItemActions`, a sibling of `ItemContent`, never inside it. The content
  takes the remaining width and truncates its title and description, so the actions keep theirs.
</Callout>

## Composition

```text
ItemGroup
├─ Item
│  ├─ ItemHeader         optional: a full row above
│  ├─ ItemMedia
│  ├─ ItemContent
│  │  ├─ ItemTitle
│  │  └─ ItemDescription
│  ├─ ItemActions
│  └─ ItemFooter         optional: a full row below
└─ ItemSeparator
```

## Examples

### Variants

`default` is borderless and sits flush in whatever holds it. `outline` draws its own border, so a
row reads as a distinct card. `muted` fills with the muted surface, for a row that is present but
demoted, like a robot in maintenance among active ones.

### Sizes

`size` is `default`, `sm` or `xs`, three steps of one scale: each trims the row's padding and the
gap between media and text, and shrinks the icon tile with them (40, 32 and 24px). `xs` also
tightens the space between title and description. Use the small sizes for lists in
sidebars and popovers, where rows repeat tightly.

<Preview demo="item/sizes">

</Preview>

### Media

`ItemMedia` has three variants. `default` leaves its content unstyled, for something that already
carries its own size, like a status dot or an `Avatar`. `icon` puts an icon on a muted tile.
`image` crops whatever `<img>` it wraps to a fixed square that shrinks with `size`.

<Preview demo="item/media">
  <Media client:load />
</Preview>

### Header and footer

`ItemHeader` and `ItemFooter` each take a full row, above and below the media and content line.
Use them for metadata that applies to the whole item, such as an identifier and status on top, or
progress underneath, without squeezing it into the description.

<Preview demo="item/header-footer">
  <HeaderFooter client:load />
</Preview>

### Group with a separator

`ItemGroup` is `role="list"` and every `Item` inside it becomes a `listitem`, so assistive
technology reads the rows as a list with a count. `ItemSeparator` marks the boundary between rows
in place of each item drawing its own border; it is decorative, so it doesn't break the list.
Here the group sits inside a `Card`, which is the usual home for a settings-style list.

<Preview demo="item/group">
  <Group client:load />
</Preview>

### As a link

`asChild` hands the row's classes to an anchor, so the whole item is one link and one tab stop,
and the row tints on hover. A linked item keeps its link role — it never becomes a `listitem` —
so put a set of linked rows in a `nav` rather than an `ItemGroup`.

## Guidelines

<Guidelines
  do={[
    "Keep the title to a name and the description to one line of state.",
    "Use `ItemMedia variant=\"icon\"` when every row in the list has an icon, so the titles align.",
    "Use `asChild` with an `<a>` when the whole row navigates.",
    "Wrap a set of rows in `ItemGroup`, so they are announced as a list.",
  ]}
  dont={[
    "Don't put several competing buttons in `ItemActions`; one action or one menu reads cleanly.",
    "Don't mix `outline` and `default` rows in one group unless the border carries meaning.",
    "Don't nest a link inside an `Item` that is itself a link.",
    "Don't rely on the description for key information: it clamps to two lines.",
  ]}

## Accessibility

`ItemGroup` renders `role="list"` and each `Item` inside it `role="listitem"`; outside a group an
`Item` is a plain row with no role. An `Item` with `asChild` keeps the semantics of the element you
give it, and its focus ring shows on `:focus-visible` only.
