## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@robomous/ui-core";

export function DatasetBreadcrumb() {
  return (
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="/datasets">Datasets</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>pallet-detection</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  );
}
```

<Callout title="The last crumb is not a link">
  The page you're standing on is a `BreadcrumbPage`, never a `BreadcrumbLink`: there is nowhere to
  go, so `aria-current="page"` is all it needs to say. Put `BreadcrumbSeparator` between items, as a
  sibling of `BreadcrumbItem`, not inside one.
</Callout>

## Composition

```text
Breadcrumb
└─ BreadcrumbList
   ├─ BreadcrumbItem
   │  ├─ BreadcrumbLink
   │  ├─ BreadcrumbPage
   │  └─ BreadcrumbEllipsis
   └─ BreadcrumbSeparator
```

## Examples

### Trail

Every ancestor is a link and the current page is the last, unlinked crumb. Link text matches the
title of the page it leads to, so a reader can tell where each link goes. Pass `asChild` to
`BreadcrumbLink` to render your router's link in place of an `<a>`.

### Collapsed trail

A trail too deep to show in full keeps its first and last crumbs and folds the middle into a
`BreadcrumbEllipsis`. Make the ellipsis the trigger of a `DropdownMenu` that lists the hidden
crumbs, so they stay reachable. The trigger needs an `aria-label`, because the ellipsis itself is
hidden from assistive tech.

</Preview>

### Icon as the root

An icon can stand in for the first crumb to save width, as long as the link carries an
`aria-label`. Use it for a home or workspace root that everyone recognises; keep words for
everything below it.

<Preview demo="breadcrumb/with-icon">
  <WithIcon client:load />
</Preview>

### Long names

Crumbs named by users can be as long as they like. Cap the last one with `truncate`, turn off
wrapping on the list with `flex-nowrap`, and let the item shrink with `min-w-0`. Keep the full name
in a `title` so nothing is lost.

<Preview demo="breadcrumb/long-names">

</Preview>

### Custom separator

`BreadcrumbSeparator` accepts children, so a slash can replace the chevron for a path-like trail,
such as an organisation, a project and a resource. It stays `aria-hidden` whatever you put in.

## Accessibility

`Breadcrumb` renders a `<nav aria-label="breadcrumb">` around an ordered list, so screen readers
announce a breadcrumb landmark and the position in the trail. `BreadcrumbPage` carries
`aria-current="page"`, and the separators and ellipsis are `aria-hidden`.
