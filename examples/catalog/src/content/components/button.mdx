## Usage

```tsx
import { Button } from "@robomous/ui-core";
```

```tsx
<Button>Save changes</Button>
<Button variant="outline">Cancel</Button>
<Button variant="destructive" size="sm">
  Delete
</Button>
```

A plain `Button` never submits a form: it renders `type="button"` unless you pass `type="submit"`.

## Composition

```text
Button
└─ <PlusIcon data-icon="inline-start" />
```

## Variants

Six variants, one intent each. `default` is the page's single primary action; `destructive` is
the only one wearing a status colour, because it ends something. There is no `success` button.

An icon reads as part of the label. `data-icon="inline-start"` or `"inline-end"` tells the button
which side to pad.
