## Usage

```tsx
import {
  Button,
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from "@robomous/ui-core";
import { EllipsisIcon } from "@robomous/ui-core/icons";

export function RowActions() {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button variant="ghost" size="icon" aria-label="Row actions">
          <EllipsisIcon />
        </Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent align="end">
        <DropdownMenuItem>Rename</DropdownMenuItem>
        <DropdownMenuItem variant="destructive">Delete</DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  );
}
```

<Callout title="Choosing an item closes the menu">
  Every item closes the menu on select. To keep it open, as for a set of checkboxes, call
  `event.preventDefault()` in `onSelect`. To open a dialog from an item, keep the dialog's `open`
  in state outside the menu and set it from `onSelect`.
</Callout>

## Composition

```text
DropdownMenu
├─ DropdownMenuTrigger
└─ DropdownMenuContent          portals itself; min-w-32 is a floor, not the trigger's width
   ├─ DropdownMenuLabel
   ├─ DropdownMenuGroup
   │  └─ DropdownMenuItem
   │     └─ DropdownMenuShortcut
   ├─ DropdownMenuCheckboxItem
   ├─ DropdownMenuRadioGroup
   │  └─ DropdownMenuRadioItem
   ├─ DropdownMenuSeparator
   └─ DropdownMenuSub
      ├─ DropdownMenuSubTrigger
      └─ DropdownMenuSubContent
         └─ DropdownMenuItem
```

## Examples

### An account menu

A label naming who is signed in, a group of destinations, a separator and a sign-out. Icons and
`DropdownMenuShortcut` hints are optional per row. In a header the trigger sits on the trailing edge,
so `align="end"` lines the menu up with its right edge.

<Preview demo="dropdown-menu/basic">
  <Basic client:load />
</Preview>

### Checkbox items

Independent toggles that the reader flips in one visit, such as table columns. Prevent the default
on `onSelect` so the menu stays open between clicks. The `All columns` row shows the third state:
checked, unchecked, or a dash when only some are on.

<Preview demo="dropdown-menu/checkbox-items">
  <CheckboxItems client:load />
</Preview>

### Radio group

One choice from a short list, with the check marking the current value. The group is one tab stop
and the arrow keys move between its rows, as they do in a standalone `RadioGroup`.

<Preview demo="dropdown-menu/radio-group">
  <RadioGroup client:load />
</Preview>

### Submenu

Group related actions behind one row so the top level stays short. A submenu opens on hover or the
right arrow, and follows the same no-exit-animation rule as its parent.

<Preview demo="dropdown-menu/submenu">
  <Submenu client:load />
</Preview>

### Destructive item

`variant="destructive"` colours a row's text and icon before focus lands, and it is the only item
variant that carries a status colour. Put it last behind a separator, and have it open a
[DestructiveActionModal](/components/destructive-action-modal) rather than act on select.

<Preview demo="dropdown-menu/destructive">
  <Destructive client:load />
</Preview>

### Inset items

`inset` pads a label or an item to the icon column, so a menu that mixes iconed and plain rows
still reads as one aligned column.

## Guidelines

<Guidelines
  do={[
    "Use it for actions on one object, and give an icon-only trigger an `aria-label`.",
    "Order items by frequency, with destructive ones last behind a separator.",
    "Open a confirmation from a destructive item instead of acting immediately.",
    "Use `align=\"end\"` for triggers at the trailing edge of a row or toolbar.",
  ]}
  dont={[
    "Don't use it to choose a form value; a Select is built for that.",
    "Don't put forms or long content inside; use a Popover.",
    "Don't nest submenus more than one level deep.",
    "Don't hide the only way to do something in a menu a reader may never open.",
  ]}

## Accessibility

Radix gives the trigger `aria-haspopup="menu"` and `aria-expanded`, the surface `role="menu"` and
its items `menuitem`, `menuitemcheckbox` or `menuitemradio`. Focus moves into the menu on open,
and typing a letter jumps to the next matching item.
