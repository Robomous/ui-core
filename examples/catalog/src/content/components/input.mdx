## Usage

```tsx
import { Input } from "@robomous/ui-core";
```

```tsx
<Input placeholder="warehouse-cameras" aria-label="Project name" />
```

A bare `Input` needs its own `aria-label`; pair it with `Field`/`FieldLabel` instead when there is
a visible label and, often, a description to attach through `aria-describedby`.

## Composition

```text
Input
```

## Disabled

Disabled keeps the arrow cursor and drops the opacity: nothing will respond to focus or a
keystroke.

## Invalid

`aria-invalid` styles the invalid state directly, so a screen reader and the stylesheet agree on
the same attribute.
