## Usage

```tsx
import { Spinner } from "@robomous/ui-core";

export function SyncStatus() {
  return (
    <p className="flex items-center gap-2 text-muted-foreground">
      <Spinner />
      Syncing telemetry from rb-07
    </p>
  );
}
```

<Callout title="Say what is loading when there is more than one">
  Each `Spinner` is a `role="status"` region labelled "Loading". Pass your own `aria-label`, such as
  `Loading detections`, so a page with several spinners does not repeat the same word.
</Callout>

## Composition

```text
Spinner      a lucide glyph with role="status"
```

## Examples

### With text

The most common use: a short line that names the work, with the spinner in front. The text carries
the meaning for everyone; the spinner only shows the wait is not over.

<Preview demo="spinner/default">
  <Default client:load />
</Preview>

### In a button

`Button` has no `isPending` prop. Compose a `Spinner` into it with `data-icon="inline-start"` and
disable the button yourself, so a press cannot fire twice. Change the label to say what is happening.

<Preview demo="spinner/in-button">
  <InButton client:load />
</Preview>

### Sizes and colour

The default is `size-4`. Use `className` to resize it with a `size-*` utility; it takes the text
colour, so a muted or primary tone is a plain colour utility. Match the size to the type beside it.

<Preview demo="spinner/sizes">
  <Sizes client:load />
</Preview>

### In a panel

When a region has nothing to show yet, centre a spinner in the space the content will fill, so
nothing shifts when it arrives. When you know the shape of the content, prefer a `Skeleton`.

## Accessibility

`Spinner` renders the lucide `Loader2` glyph with `role="status"` and `aria-label="Loading"` already
set, so mounting one is announced politely. Override `aria-label` to name what is loading. The
spin is plain CSS animation, which the stylesheet collapses under `prefers-reduced-motion`, so the
text beside it should always say what is going on.
