## Usage

```tsx
import { Spinner } from "@robomous/ui-core";
```

```tsx
<Spinner />
```

`Spinner` is a lucide glyph with `role="status"` and `aria-label="Loading"` already set: nothing
else needs announcing.

## Composition

```text
Spinner
```

## Alone

A bare `Spinner`, sized like an icon and spinning on its own.

## In a Button

There is no `isPending` prop on `Button`: compose a `Spinner` into it with `data-icon="inline-start"`
and disable the button yourself, so a press cannot fire twice.
