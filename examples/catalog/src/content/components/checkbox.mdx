## Usage

```tsx
import { Checkbox, Label } from "@robomous/ui-core";
```

```tsx
<div className="flex items-center gap-2">
  <Checkbox id="terms" />
  <Label htmlFor="terms">Accept the terms of use</Label>
</div>
```

`Checkbox` renders a `button` with `role="checkbox"` and `type="button"`, so pressing it never
submits a form. Inside a `<form>`, Radix adds a hidden native input, so `name` and `value` post as
a native checkbox would. Pair it with a `Label` through `htmlFor`.

A checkbox is for a choice that takes effect when the form is saved. A setting that applies the
moment it changes is a [Switch](/components/switch).

## Composition

```text
Checkbox
```

## Indeterminate

`checked="indeterminate"` renders `aria-checked="mixed"`: a select-all over rows that are only
partly chosen. The box fills as it does when checked but draws a dash, not a tick, so a partial
selection never reads as a full one. The state is the caller's to derive.

## Invalid

`aria-invalid` on the checkbox paints the destructive ring; `data-invalid` on the `Field` colours
its label. The message and `aria-describedby` are the call site's.
