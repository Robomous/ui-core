# Components

Fifty-four components, one file each in `src/components/`, exported by name from `src/index.ts`.
The package is built on top of shadcn/ui: a component enters from the shadcn registry through
`components.json` (`pnpm dlx shadcn@latest add <name>`), is adapted to the rules in
[DESIGN.md](../DESIGN.md), and is owned here from then on.
The file is the reference for anatomy, variants and class strings; this table says what each one
is for and where its behaviour comes from. Every one of them has a page, with live demos and a
generated API table, in the docs site under `examples/catalog/` (`pnpm docs:dev`).

Every region that scrolls inside a component fades the edge that still has content behind it,
with shadcn's `scroll-fade-x` / `scroll-fade-y` (vendored in `src/theme/shadcn.css`): Attachment's
group, CodeBlock's and Snippet's code, Combobox's and Command's lists, Select's viewport,
SidebarContent, ScrollArea's viewport and Table's container. Each is written
`supports-[animation-timeline:scroll()]:scroll-fade-*`: without scroll-driven animations the
utility would fade both ends all the time, even when nothing overflows, so those browsers get hard
edges instead. A mask erases everything at its element's edges, borders, rings and shadows
included, so it goes on the scroller and never on a surface that draws its own border: that is why
Table's border lives on a `table-card` around the container, and why the popover menus
(DropdownMenu, ContextMenu), whose content is both the scroller and the shadowed surface, carry no
fade.
